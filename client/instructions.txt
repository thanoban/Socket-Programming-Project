Start the client program.

When the program asks for your name, enter a unique client name (example: HostA, HostB).

After connecting, you can use these commands:

msg <target_name> <your message>
Sends a text message to the target client through the server.

file <target_name> <path/to/file>
Sends a file to the target client.

help
Shows all available commands.

quit
Disconnects from the server and closes the client.

The client connects to the server using the IP and port set in the code.

The first thing the client sends is your client name.
The server uses this to identify you and save your socket.

A background thread runs to receive messages and files from the server without blocking your input.

File transfers follow the protocol:

FILE|filename|filesize


Text messages follow the protocol:

TEXT|


After that, the client sends the actual message or file.
